# Contributing

By submitting a pull request, you agree that your contribution is
licensed under the same terms as this repository (CC BY 4.0 for
content, MIT for code) and that you have the right to submit it.

## Scope

This repository contains descriptive material only. Contributions
that add documentation, case titles, framework classifications, or
methodology descriptions are welcome.

Contributions that would disclose proprietary material — payloads,
detection criteria, scoring formulas, or execution runners — are not
accepted in public repositories.

## Security disclosures

Do not open a public issue for security vulnerabilities in this
documentation. Email info@logic4hack.com with reproduction steps
and potential impact.

For licensing or commercial use of the Logic4Hack toolchain, contact
info@logic4hack.com.
